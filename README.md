# ♟️ Chess Game – Java Swing

## Overview

This project is a fully functional Chess Game developed in Java using Java Swing for the graphical user interface. The application implements core Object-Oriented Programming (OOP) principles and provides an interactive environment where two players can play chess following standard chess rules.

The project was developed as part of academic learning to strengthen understanding of Java programming, GUI development, game logic implementation, and OOP concepts.

---

## Features

* Interactive graphical chess board
* Two-player gameplay
* Turn-based move management
* Valid move verification
* Piece-specific movement rules
* Capturing opponent pieces
* Check detection
* Checkmate detection
* User-friendly Java Swing interface
* Object-Oriented design architecture
